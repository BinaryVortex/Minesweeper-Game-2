# Legendary Minesweeper

Minesweeper Game built with HTML, CSS and JavaScript.

![Game Screenshot](./Screenshot%202024-09-15%20173953.png)

A classic Minesweeper implementation with a modern look and simple controls. Play directly in the browser—no build tools required.

## Features

- 10x10 grid with 20 mines
- Reveal cells by clicking
- Recursive empty-cell reveal (flood fill)
- Game status (Game Over / You found all the mines)
- Reset button to start a new game
- Lightweight: single HTML, CSS and JS files

## How to play

1. Open `index.html` in your browser.
2. Click a cell to reveal it.
3. If you click a mine, the game ends and all mines are shown.
4. Reveal all non-mine cells to win.

## Run locally

1. Clone the repo:

   git clone https://github.com/BinaryVortex/Minesweeper-Game-2.git

2. Open `index.html` in your preferred browser (double-click or serve with a local web server).

## Customize

- Change grid size or mine count: edit `script.js` (variables control grid generation and number of mines).
- Adjust styles/theme: edit `style.css` (fonts, colors, sizing).
